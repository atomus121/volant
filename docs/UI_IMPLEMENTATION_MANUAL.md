# Volant · 航道 Current UI/UX 执行手册

本手册用于在新的会话中从当前代码基础新实现整套 GPUI UI/UX。它描述已确认的 `航道 · Current` 主窗口与设置界面，以及验收后的“紧凑速添”新建下载界面；不是新的设计探索。

> 2026-11-14 验收修订：正文、元信息与数据字号整体上调；左侧“下载目录”“设置”左对齐；
> 速度带改为平滑面积折线图；任务行仅保留一条进度条；默认窗口为 1180×760、最小为 960×560；
> 点击行尾展开详情图标后详情栏在中栏右侧展开，窗口自动补足详情宽度；设置增加“代理”分页；
> 新建下载的次级操作改为“添加”，支持拖放种子，探测失败时在输入框尾端显示重试图标。
> 本节优先于下方早期冻结规格中与这些项冲突的文字。

## 1. 交付目标

把 `crates/app-gpui/src/app.rs` 的现有界面收敛到以下三个标准窗口：

1. 主窗口：左侧队列、中央实时传输带与任务列表、右侧任务详情。
2. 设置窗口：左侧分类、右侧单页设置、底部自动保存状态。
3. 新建下载窗口：紧凑单列，链接探测、文件摘要、保存位置和底部操作依次完成。

统一使用深色与浅色主题。浅色必须保持白色为主背景。

规范来源按优先级排列：

1. 根目录 [DESIGN.md](../DESIGN.md)。
2. 本执行手册。
3. [Current 主窗口与设置参考图](design-drafts/current-canonical/reference/)。
4. [紧凑速添浅色](design-drafts/current-canonical/reference/new-download-light.png)、[紧凑速添暗色](design-drafts/current-canonical/reference/new-download-dark.png)。
5. 现有 `crates/app-gpui/src/app.rs` 的交互逻辑。

如文档与截图冲突，以 `DESIGN.md` 的 token、截图的结构和本手册的行为约束三者共同判断；不得自行提出新的布局。

## 2. 明确禁止

- 不新增视觉方向。
- 不支持三档密度切换；只实现 Standard。
- 不增加顶部导航、TabBar、统计卡或第二详情栏。
- 不移除主窗口右侧详情。
- 不把设置页改成卡片网格或增加实时预览。
- 不给新建下载增加步骤向导、来源页签或额外确认页。
- 不改下载引擎、`Cmd` / `UiEvent` 边界或持久化格式。
- 不同时运行 GPUI Kit 和 Ely 两套 Theme。
- 不使用随机伪造的每连接速度。
- 不使用渐变文字、玻璃、装饰光晕、彩色侧线或 emoji 作为图标。

## 3. 技术基线

- Rust edition 2024 / 当前 MSVC toolchain。
- `gpui-kit = "=0.9.1"`，继续使用当前 `crates/app-gpui/Cargo.toml`。
- 主窗口参考尺寸 `1440×900`。
- 默认窗口 `1180×760`，最小窗口 `960×560`。
- Windows 原生窗口按钮和拖动区。
- GPUI Kit 的键盘焦点和 AccessKit 行为必须保留。
- `Cmd` / `UiEvent` 是 UI 与引擎之间唯一业务边界。

Ely 只作为同一结构的替代组件来源。除非另立分支，不要把它加入当前 Cargo 依赖。Ely 的 README 当前主要验证 macOS，Windows 落地需要单独验收。

## 4. 推荐文件组织

不要把更多 UI 继续堆进单个 `app.rs`。建议在同一个 crate 内拆分：

```text
crates/app-gpui/src/
  app.rs                 现有状态、事件处理和应用启动入口
  theme.rs               Current 浅/深色 token 与焦点环
  ui/
    mod.rs
    shell.rs             标题栏、主窗口三栏骨架
    queue.rs             速度带、任务表、任务行
    inspector.rs         右侧任务详情
    settings.rs          设置窗口
    add_download.rs      新建下载窗口
    status.rs            状态颜色、圆点和文案
```

这是实现建议，不是要求一次性重写。可以先建立 `theme.rs` 和三个屏幕组件，再逐步替换 `app.rs` 中的 render 函数。

## 5. 主题接入

### 5.1 唯一主题入口

创建只负责语义映射的 helper：

```text
VolantColors {
    canvas
    titlebar
    surface
    rail
    sunken
    hover
    selected
    selected_border
    text
    muted
    faint
    border
    border_strong
    primary
    primary_text
    current
    current_soft
    flow_from
    flow_to
    success
    warning
    danger
}
```

`VolantColors` 根据 `ThemeMode::Light` / `ThemeMode::Dark` 返回固定值。布局组件不得直接写十六进制颜色。

现有设置中的 `AppThemeMode::System`：

- 启动时读取系统浅/深色偏好。
- 系统主题变化时重新解析并更新 GPUI Kit 的 `ThemeMode`。
- 用户选择 `浅色` 或 `深色` 后覆盖系统结果。
- 主题切换不重建窗口，不改变布局、组件尺寸或状态文案。

### 5.2 Token 约束

所有 token 见 `DESIGN.md` frontmatter。关键规则：

- 浅色主背景、内容面板和弹窗始终为 `#FFFFFF`。
- 浅色选中行只使用 `selected_surface` 浅底和 `selected_border` 细边。
- 深色背景为 `#101318`，侧栏为 `#12161B`，内容面为 `#15191F`。
- `current` 只用于当前任务、焦点、选中边界和非装饰性状态。
- 成功、警告、失败只出现在状态点、短文本和极轻底色中。

### 5.3 GPUI Kit Theme

优先把 `VolantColors` 映射到 GPUI Kit 的语义 `Theme` 字段；使用组件自身的 hover、active、focus 和 disabled 状态。

不得：

- 给每个组件分别传一套主题色。
- 在按钮或输入上重复写死边框和阴影。
- 用 UI 内部状态替代 `ThemeMode`。

## 6. 主窗口

### 6.1 结构

```text
Application
└─ TitleBar                                  34px
└─ HStack
   ├─ QueueRail                              196px
   ├─ MainWorkspace                          flexible
   └─ DetailInspector                        260px
```

主区域固定 `22px` 内边距和 `16px` 垂直间距。任务列表是唯一滚动容器。

### 6.2 QueueRail

从上到下：

1. `V` 标记 + `Volant` + `下载队列`。
2. 全宽主按钮 `新建下载`，带加号。
3. 小标题 `队列`。
4. 四个筛选：
   - `全部下载` + 数量
   - `进行中` + 数量
   - `已完成` + 数量
   - `失败` + 数量
5. 底部工具：
   - `下载目录`
   - `设置`

尺寸：

- 栏宽 `196px`。
- 内边距 `15px 11px 12px`。
- 导航项最小高度 `32px`，圆角 `7px`。
- 图标 `13px`，文字 `11.5px`。
- 选中态使用 `selected_surface` + `selected_border`。
- 当前筛选显示对整个 `SidebarMenu` 状态负责；点击后更新 `filter`、数量不变、选择过滤结果中的第一项。

### 6.3 Page Header

第一行：

- 左侧：`全部下载`，`24px / 630 / 1.15`。
- 左侧第二行：`5 个任务 · 1 个正在传输`，`9.5px`，使用 muted。
- 右侧：`添加链接` 主按钮，带 `+` 图标。

注意：左侧栏按钮是 `新建下载`，主区按钮是 `添加链接`。两者打开同一个新建下载窗口，不要统一文案。

### 6.4 Speed Band

结构：

```text
HStack
  SpeedBlock       150px
  ConnectionBars   flex
  TransferMeta     auto
```

规格：

- 最小高度 `70px`。
- 内边距 `12px 16px`，列间距 `20px`。
- 背景为 surface；边框 1px；圆角 `8px`。
- 左侧：`18.7`（22px 等宽）+ `MB/s`（10px muted）。
- 中央：最近 16 个总速度样本组成的平滑面积折线图，末端显示小圆点；
  没有活动流量时不画图。
- 右侧两列：
  - `活动连接` / `8 / 8`
  - `剩余` / `约 14 秒`

速度折线：

- 高度取最近速度样本归一化结果。
- 线条、半透明面积和末端圆点使用 `current`。
- 不得加入随机抖动。

如果引擎尚未提供逐连接速度：

- 折线使用 `Row.speed_history` 的最近 16 个总速度样本。
- 不得绘制第二条分段连接进度轨。
- 不得把总速度平均后假装成独立连接速度。
- 等以后 `UiEvent` 增加真实 per-connection 数据，再逐条映射。

### 6.5 Queue

列固定为：

```text
| File                  | Progress 190px | Size 82px | Status 78px | Actions 88px |
```

- 列间距 `12px`，左右 padding `11px`。
- 表头高度 `31px`，使用 faint 9px。
- 行最小高度 `59px`，上下 padding `7px`。
- 行内图标：`30×30px`，`7px` 圆角，1px 边框。
- 文件主行 `11.5px / 580`，说明行 `9.5px`，单行省略。
- 进度条高 `3px`，圆角。
- 每个任务只显示一条 `3px` 进度条，不再显示分段微轨。
- `状态` 后固定显示开始/暂停、删除、展开详情三个图标按钮。
- 行 hover 使用 `hover`；选中使用 `selected_surface` + 1px `selected_border`。
- 当前行同时满足 hover 和 selected 时，selected 优先。
- 无边框以外的阴影。

行为：

- 点击任意行：设置 `selected = Some(row.id)`，不自动打开详情。
- 过滤变化：选择当前过滤结果第一项；没有结果时 `selected = None`。
- 活动/等待/暂停/完成/失败均保留在列表中。
- 列表滚动时速度带和页面标题不滚走。

### 6.6 Status

文本和颜色：

| 数据状态 | 文案 | token |
|---|---|---|
| Active | 下载中 | current |
| Probing | 正在读取 | current |
| Queued | 等待 | faint |
| Paused | 已暂停 | warning |
| Done | 已完成 | success |
| Seeding | 做种中 | success |
| Failed | 失败 | danger |

状态必须有 6px 圆点。不能在只有颜色的情况下隐藏文本。

### 6.7 Detail Inspector

从上到下：

1. `任务详情` 和更多按钮。
2. `48×48px` 文件图标。
3. 当前文件名，`15px / 610 / 1.35`。
4. 状态胶囊。
5. `传输`：
   - `已下载`
   - `当前速度`
   - `连接`
   - `预计剩余`
6. `保存位置`：
   - 完整路径，过长省略但 tooltip 提供全文
   - `可续传`
7. 底部固定动作：
   - `暂停下载` / 暂停后的 `继续下载`
   - `打开所在位置`

未选中任务或不点击展开详情图标时不显示详情栏。点击行尾展开详情图标后，窗口自动扩宽以补足 `260px` 详情栏所需空间，
使中栏保持原工作宽度；窄窗口下左栏同时从 `64px` 图标栏恢复为完整侧栏。详情栏右上角
使用 `X` 关闭当前详情，并恢复自动扩宽前的窗口宽度。

## 7. 设置窗口

窗口尺寸 `700×610`，原生标题栏 `34px`。

结构：

```text
Settings Dialog
└─ HStack
   ├─ Category Rail 176px
   └─ Settings Page
└─ Footer 41px
```

左侧分类：

- `下载`（当前）
- `连接`
- `代理`
- `集成`
- `外观`

右侧当前页：

- 标题 `下载`。
- 说明：`这些设置会影响新加入队列的任务，正在运行的任务保持当前参数。`

分组和顺序固定：

1. `并发`
   - `同时下载`：下拉选择，范围 `1..=20`
   - `每任务连接`：下拉选择，范围 `1..=32`
2. `保存`
   - `下载目录`：文本输入 + 文件夹按钮
   - `全局限速`：下拉选择
3. `系统集成`
   - `监视剪贴板`：Switch，默认开
   - `捕获后直接开始`：Switch，默认关
   - `删除任务前确认`：Switch，默认开
   - `主题`：三段选择 `系统 / 浅色 / 深色`

设置行为：

- 调整即应用。
- 写入配置后显示/保持 `所有更改自动保存`。
- 目录不可写时保留用户输入，显示具体原因，不静默更换目录。
- 设置失败不能清空已输入值。
- 不添加保存按钮。

尺寸：

- 设置行最小高度 `44px`。
- 标签列可伸展；控制在右侧同一条基线。
- 文本输入、文件夹按钮和下拉触发器高度统一为 `32px`。
- 数值下拉宽度 `136px`，默认显示 5 项，超出后鼠标滚动。

## 8. 新建下载窗口

最终采用 **紧凑速添**。窗口尺寸 `560×350`，原生标题栏 `34px`，单列布局，底部操作栏 `48px`。

```text
Dialog
├─ TitleBar                         34px
├─ Content
│  ├─ Heading + short explanation
│  ├─ URL InputGroup + 添加
│  ├─ State area
│  └─ Destination row
└─ Footer                            48px
```

### 固定内容顺序

1. 标题：`新建下载`
2. 副标题：`粘贴链接，确认后立即开始。`
3. URL 输入和紧凑的 `添加` 按钮。
4. 状态区：
   - 空白：`粘贴链接后显示文件名、大小和保存位置。`
   - 探测中：小 spinner + `正在读取文件信息…`
   - 成功：单行文件摘要
   - 失败：单行错误提示 + `重试`
5. 成功后才出现保存位置行。
6. 底部：`Enter 开始下载`、`取消`、`立即下载`。

### 成功态

文件摘要严格使用一行：

- `29×33px` 文件图标
- 文件名
- 下一行只显示来源域名和 `支持断点续传`
- 右侧显示文件大小
- 右侧状态：`可下载`

保存位置紧接摘要下方：

- 文件夹图标
- 完整路径，单行省略
- `更改`

`立即下载` 仅在当前 URL 已完成成功探测时启用。

### 删除项

以下内容和行为不得出现在新建下载窗口：

- 右侧“这次会发生什么”说明栏。
- 三段流程步骤。
- `预计速度`、连接建议和 Content-Disposition 来源说明。
- `以后从浏览器捕获时直接开始`复选框；它属于设置页。
- 重复的格式说明、文件回执标题、多余状态胶囊和额外主按钮。
- 任何嵌套卡片或二次确认页。

### 状态规则

- 空白：保留 URL 输入焦点；粘贴/输入链接或拖入种子后自动探测；`立即下载` 禁用。
- 探测中：保留用户输入；禁止重复提交；`添加` 禁用。
- 成功：显示摘要、路径和可用的 `立即下载`。
- 失败：保留 URL 和焦点；输入边框使用 danger；错误提示只出现一次；输入框尾端的重试图标可再次探测。
- Enter：输入结束后触发现测；探测成功后触发 `立即下载`。
- Escape：关闭窗口。

### 尺寸

- 对话框：`560×350px`。
- 内容区左右 padding：`24px`。
- 顶端 padding：`17px`。
- URL 行高：`38px`。
- 按钮高度：`32px`；`添加` 与 URL 行同高。
- 成功摘要区域高约 `55px`。
- 保存位置行高约 `36px`。
- 底部高度：`48px`。

### 删除确认

- 窗口宽度 `360px`。
- 复选框文案为 `不再显示`，与 `取消`、`删除`、`彻底删除` 位于同一水平行。
- `删除` 使用标准次级按钮；`彻底删除` 使用 danger 文字、同色 1px 边框、透明背景。

## 9. GPUI Kit 使用对照

| UI 元素 | 组件 |
|---|---|
| 窗口标题栏 | `TitleBar` |
| 左侧队列导航 | `Sidebar`、`SidebarMenu`、`SidebarHeader`、`SidebarFooter` |
| 主 / 次 / ghost 动作 | `Button` + `ButtonVariants` |
| 任务进度 | `Progress` |
| 详情键值 | `DescriptionList` |
| URL、目录、限速 | `Input`、`Select` |
| 开关 | `Switch` |
| 新建/设置窗口 | `Dialog` |
| 任务列表扩展 | `List` / `ListDelegate` |
| 错误提示 | `Alert` 或 `Notification` |
| 图标 | GPUI Kit Lucide icons |
| 键盘焦点 | GPUI Kit focus / AccessKit |

速度面积图、单条任务进度轨和状态圆点属于数据图形，由普通 GPUI 元素组合。
它们不是新的 UI 框架。

种子文件选择窗口的列表头依次显示全选复选框、`文件`、`类型`、`大小`；类型取文件扩展名并大写显示。

不要为了 5 条任务直接使用 `DataTable`。如果未来任务数达到需要虚拟化的规模，再把任务列表迁移到 `List` / `VirtualList`，保持相同的行信息。

## 11. 状态与反馈

### 任务状态

- 进度数字即时更新。
- 速度使用 400–500ms 采样窗口，并保留最近一分钟历史。
- 完成的任务显示 `已完成`、最终大小、完成时间。
- 暂停任务显示 `已暂停`，按钮文案改为 `继续`。
- 失败任务显示 `失败`，详情处给出用户可理解的失败原因。

### 空队列

保持主窗口三栏结构。主区显示：

- `还没有下载任务`
- `粘贴链接或从浏览器开始一次下载。`
- `添加链接` 按钮

右侧详情显示 `选择一个任务` 和 `从左侧列表选择任务。`

### 错误

- 403：提示检查链接是否过期或需要登录。
- 404：提示检查链接是否有效。
- 超时：提示检查网络后重试。
- 目录不可写：保留路径，提示更换下载目录。
- 磁盘不足：显示可用空间与所需空间。

不得只显示后端原始错误文本。

## 12. 键盘与焦点

- Tab 顺序：标题栏 → 队列导航 → 主区标题动作 → 速度带 → 任务行 → 详情动作。
- 左右方向键只在显式可聚焦控件组中使用。
- 上下方向键可切换任务选中项。
- Enter 在新建下载中执行“立即下载”，前提是探测成功。
- Escape 关闭设置、新建下载窗口，或关闭当前任务详情。
- 焦点环使用 2px `current`，偏移 2px。
- 图标按钮必须有 `aria_label` 或 GPUI AccessKit 名称。
- 不使用只靠 hover 才能看到的操作。

### 鼠标与右键

- 右键任务显示：`开始`、`暂停`、`删除`、`彻底删除`、`复制下载链接`、`打开所在位置`。
- 双击进行中的任务暂停；双击暂停任务开始；双击已完成任务打开文件；双击失败任务重试。
- 双击判断使用 600ms 内同一任务的两次左键操作，同时兼容系统原生多击计数。

## 13. 动效

只实现状态动效：

- 行 hover / selected：背景和边框 140ms 过渡。
- 主题切换：允许约 160ms 颜色交叉淡化；禁止布局动画。
- 进度条、速度数字和连接条在数据变化时即时更新。
- 错误提示出现时即时插入；不抖动整个窗口。
- 不加入页面进场、背景循环动画或装饰性脉冲。

## 14. 响应式与窗口

- 主参考视口：1440×900。
- 窗口低于 `1000px` 时，左侧队列栏折叠为 `64px` 图标栏。
- 选中任务时自动扩宽窗口以容纳详情栏；详情关闭后恢复原宽度。
- 最小窗口 960×560：保持中央任务列完整，并阻止继续缩窄。
- 设置和新建下载窗口不得被主窗口截断；优先级是保证主操作按钮可见。
- Windows DPI：100%、125%、150%、200% 均需人工检查。

- 正文、辅助文字和焦点环是否达到 4.5:1 / 3:1。
- 所有文案是否与参考截图一致。

## 16. 完成定义

满足以下条件才算完成：

- 三个屏幕都按结构复现，没有新增或删除区域。
- 深色/浅色都由同一语义 token 集驱动。
- 主窗口所有数据来自真实 `Row` 和事件，不使用随机值。
- 新建下载流程从 URL 输入走到探测成功并可加入队列。
- 暂停/继续、选择、设置修改、主题切换、空状态和错误状态可操作。
- 1440×900、窄窗口和 200% DPI 已截图检查。
- `cargo fmt`、`cargo clippy`、现有测试通过。
- 设计验收以 [DESIGN.md](../DESIGN.md)、Current 主窗口与设置参考图，以及紧凑速添的浅色/暗色参考图为准。
