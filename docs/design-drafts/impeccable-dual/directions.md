# 方向卡

## 共用产品事实

- 产品：Volant，Windows 优先的下载器。
- 主任务：添加 HTTP/HTTPS、magnet 或 `.torrent`，观察进度，暂停/继续，完成后打开文件。
- 主视口：1440×900；设置和新建下载为独立窗口。
- 真实内容：文件名称、来源域名、已下载/总大小、速度、连接数、剩余时间、保存路径和失败原因。
- 技术边界：Rust GPUI + GPUI Kit 0.9.1；主题、输入、按钮、开关、进度和可访问性沿用组件层。
- 主题约束：每组都提供浅色与暗色；浅色以白色为绝对主背景。

## 产品参考与取舍

- GPUI Kit 的真实界面以白色、灰色细线和近黑主要操作为主，控件层级清楚，适合桌面工具。
- Ely GPUI Components 的真实界面以开放留白、大字与极轻分割为特征，适合作为排版与克制的参照。
- 保留：系统化控件、清楚的选中态、紧凑数据、键盘焦点。
- 换掉：官网展示型大标题、代码样例外壳和组件目录结构；下载器主窗口必须直接进入任务。

## 交互参考与取舍

当前 GPUI 实现的路径是：

`添加链接 → 探测文件信息 → 加入队列 → 查看进度 → 暂停/继续/打开位置`

三个方向都保留这个顺序，不增加确认向导。设置变更继续即时应用，而不是增加“保存”步骤。

## A · 制图 Draftline

**北极星**：让每一段下载都像可核对的测量结果，速度与连接状态不需要解释就能被看见。

**唯一主角**：当前正在传输的文件。

**唯一主动作**：新建下载。运行中的暂停、继续与打开位置贴近任务，但视觉权重低于主按钮。

**动作结果**：新任务进入队列并成为活动文件；标尺、速度、连接与剩余时间同步切换到新任务。

**生成引擎**：工程制图与测量标记。只借其精确的标尺、网格和记录方式，不搬 CAD 工具面板。

**首屏结构**：顶部是产品名、队列筛选和新建下载；下方是一条贯穿版心的活动任务标尺；再下方是文件队列；右侧窄栏展示连接分布和保存目标。

**字体**：`Segoe UI Variable Display` / `Text`，数据与路径使用 `Cascadia Mono`。

**浅色色彩**：`#FFFFFF` 底、`#111417` 主文、`#5D666E` 次文、`#DFE3E6` 分隔、`#1E5FD3` 活动蓝。

**暗色色彩**：`#0B1119` 底、`#111A24` 面板、`#F2F5F7` 主文、`#7CA5FF` 活动蓝。

**图标**：单色线性图标，1.5–1.8px；不使用 emoji 或彩色图标。

**控件语法**：6–8px 圆角、1px 细边框、黑色/近白主按钮；数据值等宽；选中用细边界和轻底色。

**记忆点**：由重复刻度组成的传输标尺，刻度与实际进度同步变化。

**落地成本**：低。只需 GPUI 布局和现有进度数据，不需要额外图表库。

**风险**：如果刻度过度装饰，会显得像工程软件；当前只在进度条和连接读数使用。

**主动放弃**：同权指标卡、彩色状态底色、右侧统计仪表盘。

## B · 时刻 Transit

**北极星**：下载是一段从远端到本地目录的行程，当前位置比抽象百分比更容易扫读。

**唯一主角**：当前任务在队列中的位置。

**唯一主动作**：暂停或继续当前下载。新建下载保持在页头工具层。

**动作结果**：暂停时路线停止并转为灰色；继续后当前节点恢复活动色，速度与剩余时间重新更新。

**生成引擎**：路线图和时间表。借其阅读顺序与节奏，不把整个窗口做成车站显示屏。

**首屏结构**：左侧是紧凑筛选，主区以路线节点承接当前文件，任务列表在路线下方连续排列。

**字体**：系统 UI 字号更紧凑，文件名和数据走同一条基线。

**浅色色彩**：`#FFFFFF`、`#171A18`、深灰 `#5D666E`、活动绿 `#0D6B51`。

**暗色色彩**：`#101311`、`#1B201C`、`#F0F3EE`、`#80D1B1`。

**图标**：方向相同的 1.6px 线性图标；文件状态通过形状与文字双重表达。

**控件语法**：标准 tabs、列表行、圆形路线节点；主按钮和次按钮保持系统桌面语法。

**记忆点**：八段路线中的当前位置，与真实的 8 条连接数量对应。

**落地成本**：低到中。路线节点由普通 GPUI 元素组成；状态变化需要平滑更新位置。

**风险**：路线隐喻如果扩展过度，会压过任务列表；当前只用于当前任务，不让所有条目都变成线路。

**主动放弃**：全程地图化、绿色大面积铺底、装饰性“站点”图标。

## C · 档案 Folio

**北极星**：下载最终是一件被妥善保存、可以再次打开的文件。

**唯一主角**：当前选中的文件记录。

**唯一主动作**：暂停/继续；新建下载作为工具按钮常驻右上。

**动作结果**：左侧索引选择另一文件时，右侧完整记录、路径、状态和后续任务同步切换。

**生成引擎**：档案与文件索引。只借索引与文件页关系，不借用纸张纹理或仿古装饰。

**首屏结构**：上方单行工具条，左侧文件索引，右侧打开的当前文件页；没有常驻第三栏。

**字体**：系统 UI 为主体，文件名的大小与字重明显高于元数据；数字仅适度使用等宽。

**浅色色彩**：`#FFFFFF`、`#1D1B18`、`#5D666E`、`#E3DFD8` 分隔、`#2A56A2` 进度。

**暗色色彩**：`#141311`、`#1D1C19`、`#F3F0EA`、`#9DB9ED`。

**图标**：细线文件与文件夹图标，保持一致描边；不使用纹理。

**控件语法**：较大点击面积、轻边框、低层级元数据；索引行选中用整行浅底，而不是彩色胶囊。

**记忆点**：文件索引与文件页联动，完成文件仍保留完整记录。

**落地成本**：低。主要是现有列表、文本和路径数据重排。

**风险**：右侧大面积文件页可能让活跃速度不够醒目；因此把速度和剩余时间固定在文件名下方的第二层。

**主动放弃**：文件夹拟物、纸质纹理、传统三栏检查器。

## 视觉审查结论

- 三个方向在缩略图下的主结构明显不同：A 是横向标尺工作纸，B 是路线驱动的单主区，C 是索引与文件页。
- 每组浅色与暗色使用相同组件尺寸、间距、圆角和状态文案。
- 浅色全部以 `#FFFFFF` 为主背景，黑色为正文和主操作，灰色负责层级和辅助信息。
- 当前没有把候选的按钮动作接入真实业务数据，因此不声称交互已经通过。
