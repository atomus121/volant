# 概念与灰度自检

独立概念子代理未返回候选内容，因此本轮按 Skill 的回退规则自行生成内部候选，并标记“未独立生成概念与把关”。

## 适配与落地

- A 页边：适合日常下载与文件回收；唯一主角、主动作和展开结果明确。普通 GPUI 列表即可落地。
- B 白工位：适合较高任务密度和持续操作；主动作、表格与检查器路径完整。现有标题栏、按钮和输入足够。
- C 传输轨：适合强调速度与连接的产品承诺；大舞台与队列切换可走通。连接轨需要自绘，但不需要新增依赖。

## 差异检查

| 项目 | A 页边 | B 白工位 | C 传输轨 |
|---|---|---|---|
| 首屏骨架 | 开放单列文件目录 | 黑色图标轨 + 表格 + 检查器 | 队列窄列 + 当前任务舞台 |
| 字体 | 大文件名与开放排版 | 系统 UI 与数据等宽字 | 超大文件名与等宽传输数据 |
| 色彩 | 暖白、黑、灰 | 冷白、黑、灰 | 中性白、黑、灰 |
| 主视觉 | 选中行展开 | 活动行连接刻度与检查器 | 8 条连接轨道 |
| 核心交互 | 选行展开，新增后置顶 | 选行联动右侧检查器 | 切换队列项更新主舞台 |
| 记忆点 | 文件页展开 | 黑色测量尺进度 | 文件与连接轨道同步切换 |

至少一个方向明确跳出“左侧导航 + 顶栏 + 卡片 + 列表”的常见桌面工具结构：A 不使用左侧导航，C 把队列降到次级。三个方向均保持白色主导和黑白灰层级。

## 调性

- 能量：安静。下载器长时间驻留，状态变化需要清楚但不喧闹。
- 完成度：精致。对齐、字重、边框和焦点必须一致。
- 密度：A 疏、B 中密、C 疏但数据结构更强。
- 分量：中等偏轻。主操作与当前文件最重，辅助动作退后。
- 严肃度：偏庄重。只保留短而可预测的状态反馈。
