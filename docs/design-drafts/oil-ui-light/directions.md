# 浅色方向探索

## 共用产品事实

Volant 是 Windows 下载器。主任务不是“浏览下载器”，而是快速确认当前下载、控制它、继续下一项。主视口为 1440×900，设置窗口约 760×610，新建下载窗口约 650×470。内容包含 HTTP/HTTPS、magnet、`.torrent`、进度、速度、连接数、大小和保存位置。

本轮的视觉底线：白色是主背景，黑色承担正文与主操作，灰色承担层级、规则线和辅助信息。颜色只用于失败、警告和完成点，不把状态色铺成大面积背景。

## 产品参考拆解

### GPUI Kit

真实画面：[GPUI Kit 首页](references/gpui-kit-home.png)、[GPUI Kit Button 文档](references/gpui-kit-button.png)。

- 白色画布与近黑文字形成高对比，几乎没有色相干扰。
- 顶栏、侧栏、内容和页内导航通过 1px 灰色规则线分开，不依赖多套卡片阴影。
- 黑色主按钮、白底描边按钮、浅灰选中底组成清晰的控件层级。
- 标题字重明显，正文较轻；代码与数据使用等宽字体，视觉含义明确。
- 结构适合信息密集工具，但官网的营销排版、装饰网格和展示字号不应直接搬入下载器。

### Ely GPUI Components

真实画面：[Ely 首页](references/ely-home.png)、[Ely Components 总览](references/ely-components.png)。

- 大面积白色留白与超大黑色标题建立识别度。
- 辅助信息使用中灰，结构主要靠空间和极细分割，不靠边框与阴影。
- 黑色胶囊按钮承担唯一或多个同层级主操作。
- 组件总览采用“开放目录 + 细线分组”，层级清楚且没有卡片瀑布。
- 这份开放感适合方向 A 和 C；不能为了模仿官网而把下载器变成海报。

## 交互参考与取舍

交互基线沿用当前 GPUI 实现：

- 新建下载：打开窗口 → 输入或捕获链接 → 探测文件名/大小/续传 → 确认加入队列。
- 主窗口：选择任务 → 查看或展开详情 → 暂停/继续/打开目录。
- 设置：调整后立即应用并保存；失败或目录不可写时保留输入并给出原因。

借鉴 GPUI Kit 的按钮、输入、开关、进度和 Dialog 行为；借鉴 Ely 的焦点和状态可见性思路。两套主题运行时仍只选一套。

## 删除清单

| 元素 | 处理 | 理由 |
|---|---|---|
| 三张等宽汇总卡片 | 删除 | 汇总信息应在页头或当前任务周围出现 |
| 大色块状态胶囊 | 降级 | 改为小圆点 + 文本，避免彩色抢主任务 |
| 每行外层轮廓与选中底色叠加 | 合并 | 选中只保留一种视觉表达 |
| 完成任务的常驻详情 | 降级 | 只在需要时展开 |
| 第二套主题运行时 | 删除 | 组件能力重叠，实现成本与一致性风险过高 |
| 新建下载的分步向导 | 删除 | 用户只需要粘贴、确认文件、开始 |
| 装饰渐变、玻璃和彩色侧线 | 删除 | 与白色主画布和黑白层级冲突 |

## 内部候选

1. **页边 File Page**：开放白纸式列表，选中行展开详情，页头只保留任务名、速度和添加动作。
2. **白工位 White Desk**：黑色窄轨 + 数据表 + 白色检查器，外观最接近原生桌面工作台。
3. **传输轨 Transfer Track**：当前下载占主舞台，队列退到左侧窄列，分片与连接成为主视觉。
4. **收件台 Intake Desk**：新建链接常驻顶部，任务列表退到次级；适合高频捕获，但削弱已运行任务。
5. **指令带 Command Strip**：一条黑色命令带承担添加与筛选，列表铺满下方；操作快，但状态表达不够丰富。
6. **时间轴 Timeline**：按完成时间与吞吐排成横向时间条；适合回顾，不适合日常操作。

选择 1、2、3 作为对外方向：它们分别代表“记录”“工作台”“传输”三种不同的产品主角，且都能落地到现有 GPUI 组件与数据。

## A · 页边 File Page

**北极星**：让下载列表像一份干净的文件目录，当前文件通过排版和进度获得全部注意力。

**唯一主角**：已选中的活动下载。

**唯一主动作**：“新建下载”。在选中行内，暂停和打开位置降为文字动作。

**动作结果**：加入链接后，新任务出现在列表顶部并成为选中的活动行；原有列表下移，不弹回首页。

**主视口灰度**

```text
┌──────────────────────────────────────────────────────────────┐
│ V Volant       全部 进行中 已完成 失败       18.7 MB/s  [+ 新建] │
├──────────────────────────────────────────────────────────────┤
│ 下载                                        5 个任务           │
│                                                              │
│ debian-13.2...iso                             下载中      61% │
│ 421 MB / 682 MB · 18.7 MB/s · 8 连接 · 约 14 秒              │
│ █████████████████████████████████████░░░░░░░░░░░░░░░░        │
│ 暂停   打开所在位置                                           │
├──────────────────────────────────────────────────────────────┤
│ openai-paper...zip                         等待     0%  128 MB │
├──────────────────────────────────────────────────────────────┤
│ rustup-init.exe                            已暂停  51%  9.2 MB │
├──────────────────────────────────────────────────────────────┤
│ ubuntu-26.04...iso                         已完成 100%  3.5 GB │
└──────────────────────────────────────────────────────────────┘
```

**设置窗口**：顶部横向分类，主区拆成“并发 / 保存 / 捕获”三组；不使用左侧导航。控件沿同一条右对齐线排列。

**新建下载窗口**：大号单行输入，探测结果做成无边框的文件回执；文件名最大，元数据用两列，底部只有一个黑色“开始下载”。

**字体**：`Segoe UI Variable Display` 用于文件名与页标题，`Segoe UI Variable Text` 用于正文；数字启用 tabular numerals。

**色彩**：`#FFFFFF` 主底、`#111111` 正文、`#4F4F4C` 次文、`#8A8984` 辅助、`#E8E7E3` 线条、`#F6F6F3` 选中底；成功 `#2D6A52`、警告 `#8C651F`、失败 `#A8443B` 只用于小点。

**记忆点**：选中行像一张被展开的文件页，文件名与黑色进度线一起成为主视觉。

**资产与技术**：纯排版和一行连续进度；无图片。GPUI 普通列表与可展开行即可完成。

**主动放弃**：常驻详情栏、卡片网格、彩色进度条、分步向导。

## B · 白工位 White Desk

**北极星**：把下载器做成一张没有干扰的白色工作台，任务、进度和详情各归其位。

**唯一主角**：中央任务表中的活动行。

**唯一主动作**：“新建下载”。右侧检查器只服务当前选中任务。

**动作结果**：新任务进入表格第一行，连接分片图和详情同时切换到新任务。

**主视口灰度**

```text
┌────┬──────────────────────────────────────┬──────────────────┐
│ 黑 │ V Volant                        [+ 新建] │ 当前文件        │
│ 色 ├──────────────────────────────────────┤ 文件名          │
│ 图 │ 全部 / 进行中 / 已完成 / 失败         │ 进度与连接      │
│ 标 ├──────┬─────────┬──────┬──────┬───────┤ 保存位置        │
│ 轨 │ 文件  │ 进度    │ 大小 │ 状态 │ 动作  │ [暂停]          │
│    ├──────┼─────────┼──────┼──────┼───────┤ [打开位置]      │
│    │ 活动行：黑色分段进度 + 连接刻度        │                │
│    │ 等待行                               │                │
│    │ 暂停行                               │                │
│    │ 完成行                               │                │
│    │ 失败行                               │                │
└────┴──────────────────────────────────────┴──────────────────┘
```

**设置窗口**：沿用黑色图标窄轨；右侧按“队列 / 保存 / 捕获 / 外观”分组。每一行由可读标签和单个控件组成。

**新建下载窗口**：左右两栏。左侧输入链接并显示探测状态，右侧先确认保存位置和“可续传”，主按钮固定右下。

**字体**：`Segoe UI Variable` 统一界面；`Cascadia Mono` 只用于速度、百分比、路径和连接数。

**色彩**：`#FFFFFF` 主底、`#0C0C0D` 导航与正文、`#5F6469` 次文、`#DDE0E2` 线条、`#F3F5F5` 悬停、`#E8ECEB` 选中；状态色不超过 14px 的点、字或线。

**记忆点**：活动行的进度不是普通蓝条，而是一条由 8 条连接刻度组成的黑色“测量尺”。

**资产与技术**：图标采用 Radix 或 Material Symbols Sharp 风格；表格使用 GPUI 布局，不必为少量任务引入 DataTable。

**主动放弃**：无边框列表、超大展示字、左右不对称排版。

## C · 传输轨 Transfer Track

**北极星**：把“下载正在进行”变成画面本身，让速度、连接和分片在一处被看见。

**唯一主角**：主舞台上的活动下载。

**唯一主动作**：“暂停下载”。新加入任务通过页头小按钮触发，避免和当前任务的暂停争夺注意力。

**动作结果**：暂停后大号文件状态从黑色“下载中”变成灰色“已暂停”，连接轨道停止，按钮改为“继续下载”。

**主视口灰度**

```text
┌──────────────────────────────────────────────────────────────┐
│ V Volant    全部 进行中 已完成 失败                 [+ 新建] │
├──────────────────────┬───────────────────────────────────────┤
│ 队列                 │ debian-13.2.0-amd64-netinst.iso       │
│                      │ 下载中 · 18.7 MB/s · 8 连接           │
│ ● debian iso    61%  │                                       │
│ ○ openai zip     0%  │  ████████████████████████░░░░  61%    │
│ ○ rustup exe    51%  │  [8 条独立连接轨道 / 分片完成图]       │
│ ✓ ubuntu iso   100%  │                                       │
│ × dataset        9%  │ 421 / 682 MB      约 14 秒            │
│                      │ [暂停下载]  [打开下载目录]             │
└──────────────────────┴───────────────────────────────────────┘
```

**设置窗口**：左侧设置目录，主区是一条条横向控制带；数值步进器直接贴着名称，右侧用同一条细竖线对齐。

**新建下载窗口**：上半部是“链接 / 种子 / Magnet”来源切换和输入；下半部一半是文件确认，一半是目的地。进度感由来源类型和探测结果形成，不使用步骤编号。

**字体**：`Microsoft YaHei UI` 与 `Segoe UI Variable` 混排，数字用 `Cascadia Mono`；文件名使用 24px 常规字重，不堆粗体。

**色彩**：`#FFFFFF` 主底、`#171717` 主文、`#66635E` 次文、`#A2A09A` 辅助、`#E7E5E0` 线条、`#F7F6F2` 次级表面；语义色只在连接轨和状态点出现。

**记忆点**：切换队列项时，大文件名、进度和连接轨道一起更新；轨道把“8 连接”从参数变成可扫描的画面。

**资产与技术**：需要自绘连接轨道，但可由 GPUI canvas 或分段 div 完成；数据来自现有 `connections` 与 `speed`。

**主动放弃**：全局统计卡、完整详情表、装饰性图表。
